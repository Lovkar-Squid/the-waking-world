## 0.3.0-beta.4 — the star still leaves something

A star that comes down on a colony already tore no crater — no hole, no glassed floor, no scorch, no blight. The trouble was that the **Starstone it was carrying went with them**, so a strike on a town was all noise and no prize.

Now the core is left *on* the ground instead of set in the floor of a crater that does not exist: a few blocks of Starstone lying where it landed, placed into air and nothing else, so it costs the town nothing and you still get your Star Iron. If there is no room for even that — it came down through a roof — the Star Iron is dropped instead.

This is the one write the mod is allowed to make on a colony's land, and only because it takes nothing away. It is remembered like everything else, so an Hourglass of Restoration takes the meteorite back with the rest of the strike.

Everything else in 0.3.0-beta.3 is unchanged. Full changelog: https://github.com/Lovkar-Squid/the-waking-world/blob/main/CHANGELOG.md
